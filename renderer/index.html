SYNAPSE LABS · APP GUIDE

How every function works

This guide follows the exact controls visible in your Synapse Trading Agent window. Each section explains what the control does, when to use it, what it reads or changes, and what it does not do.

01 · CONTROL CENTER

Barra superior: estado, refresh y configuración

LOCAL ONLY confirma que esta aplicación trabaja desde este equipo y no usa un servidor Synapse intermedio para leer tu exchange.

↻ Refresh live data
Vuelve a consultar balance, capital, valor total, posiciones y órdenes del exchange seleccionado. Solo puede traer datos si ya guardaste credenciales.
API Setup
Abre la pantalla para guardar, actualizar o eliminar las credenciales locales cifradas del exchange activo. El formulario nunca muestra el secreto real una vez guardado.
Agent Setup
Abre la comprobación del runtime local de Hermes Agent y las preferencias de Arrow. Desde allí puedes verificar la instalación y personalizar tono o enfoque sin cambiar la política base.
02 · CONNECTION SCOPE

Active Exchange

Selecciona la cuenta que Synapse debe consultar: Binance Global, Binance US o Coinbase. El cambio de exchange vuelve a cargar sus parámetros, estado de credenciales, monitor y datos de cuenta de forma independiente.

  • La selección no ejecuta órdenes.
  • Las credenciales se guardan separadas por exchange.
  • El icono identifica visualmente el exchange activo.
03 · ASSISTANCE MODE

AI Agent (Arrow)

El interruptor activa o desactiva la asistencia de Arrow dentro del chat lateral. Cuando está activo, Arrow puede analizar el estado no secreto mostrado por Synapse y proponer controles que ya existen en la interfaz.

  • Arrow no abre posiciones ni crea operaciones nuevas.
  • Puede sugerir cambios de parámetros o del monitor mediante controles validados.
  • Si Hermes no está listo, el chat permanece bloqueado y te lleva a Agent Setup.
04 · LOCAL POSITION MONITOR

Start y Stop

El monitor consulta periódicamente el exchange desde este computador para mantener actualizado el tablero. No es un motor de trading: no abre entradas ni lanza estrategias automáticamente.

Start
Inicia la lectura local del exchange activo. Después actualiza la cuenta y marca el estado como RUNNING.
Stop
Detiene las consultas periódicas del monitor. No borra credenciales, parámetros ni datos ya mostrados.
READY / OFFLINE
READY significa que hay credenciales disponibles y el monitor está detenido; OFFLINE indica que falta configuración local.
05 · BOT CONFIGURATION

Parameters y Configure

El panel lateral es un resumen vivo de los 12 valores guardados para el exchange activo. Configure abre el formulario editable; al guardar, los valores se almacenan localmente para ese exchange.

  • Position update interval (ms): frecuencia de actualización.
  • Take profit percentage of capital: umbral de take profit del capital.
  • DCA relative percentage: proporción base de DCA.
  • DCA distance multipliers: distancias de cada nivel, por ejemplo [1, 2].
  • Stop-loss distance multiplier: multiplicador de distancia del stop-loss.
  • DCA quantity increment (%): incremento de cantidad por nivel.
  • Minimum DCA distance (%): distancia mínima antes de otro DCA.
  • Maximum open positions: límite de posiciones abiertas.
  • Stop-loss percentage: porcentaje de stop-loss.
  • DCA percentage increment: aumento porcentual entre niveles.
  • Breakeven ROI threshold: ROI a partir del cual se considera breakeven.
  • Auto-shutdown (minutes): minutos hasta detener el monitor automáticamente.

Estos valores se muestran y persisten localmente. Por sí solos no convierten al monitor en un ejecutor de órdenes.

06 · ACCOUNT SNAPSHOT

Account Balance, Available Capital, Total Value y Open Positions

Estas tarjetas son una lectura resumida del último snapshot recibido del exchange.

Account Balance
Balance de la cuenta según el exchange y el mercado mostrado.
Available Capital
Capital disponible para operar o margen libre, según la integración activa.
Total Value
Valor total calculado a partir de los datos normalizados disponibles.
Open Positions
Número de posiciones abiertas; debajo se indica el mercado, como SPOT o PERPETUALS.
07 · DIRECT EXCHANGE DATA

Open positions, Pending Orders y Close position

Esta zona muestra la respuesta directa normalizada del exchange seleccionado, no datos inventados por Arrow.

  • Open positions: lista símbolo, lado, tamaño, entrada, precio mark, PnL no realizado y riesgo.
  • Pending Orders: cambia a las órdenes pendientes y muestra símbolo, lado, tipo, precio, cantidad, estado y Reduce Only.
  • Select: marca una posición concreta para una acción posterior.
  • Close position: permanece deshabilitado hasta seleccionar una posición; después exige confirmación y valida de nuevo que la posición siga abierta y conserve la misma cantidad.
08 · LOCAL EVENT STREAM

Activity y Clear

Activity registra eventos importantes del uso local: inicio o detención del monitor, cambios guardados, respuestas de Arrow, errores y acciones realizadas.

  • El punto verde identifica eventos correctos.
  • El punto rosa marca avisos o detenciones.
  • El punto rojo indica errores.
  • Clear limpia la lista visible; no borra credenciales, parámetros ni el estado del exchange.
09 · RISK ASSISTANCE

Arrow Agent: análisis dentro de Synapse

El panel derecho es el espacio de conversación de Arrow. Recibe el snapshot actual no secreto de posiciones, órdenes, métricas, exchange y parámetros para ayudarte a interpretar riesgo y estado.

  • LIVE significa que Arrow está habilitado y Hermes está listo.
  • STANDBY significa que está apagado o falta completar Agent Setup.
  • Las acciones propuestas solo usan controles permitidos por Synapse y se aplican desde botones visibles.
10 · CONVERSATION

Pregunta a Arrow y Send

Escribe una pregunta sobre el estado actual y pulsa Send. También puedes pulsar Enter para enviar; Shift+Enter conserva un salto de línea.

  • El contador indica cuántas posiciones se incluyen en el contexto.
  • El historial reciente se conserva dentro de la conversación para preguntas de seguimiento.
  • Arrow no recibe claves API, secretos, tokens ni la clave privada de Coinbase.
  • Si solicita una acción, Synapse la valida y muestra el resultado en Activity.
11 · LOCAL SAFETY STATE

Local runtime

La línea inferior del rail resume el entorno activo: exchange seleccionado, estado local y origen de escritorio.

  • El punto verde indica que la interfaz local está disponible.
  • Local runtime · [exchange] confirma el exchange actualmente seleccionado.
  • LOCAL ENCRYPTED · DESKTOP SOURCE recuerda que las credenciales se protegen con el almacenamiento seguro de Windows y que la app corre desde el escritorio.
