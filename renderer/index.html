SYNAPSE LABS · APP GUIDE

How every function works

This guide follows the exact controls visible in your Synapse Trading Agent window. Each section explains what the control does, when to use it, what it reads or changes, and what it does not do.

01 · CONTROL CENTER

Top bar: status, refresh, and configuration

LOCAL ONLY confirms that this application runs from this computer and does not use an intermediate Synapse server to read your exchange.

↻ Refresh live data
Queries the selected exchange again for balance, capital, total value, positions, and orders. It can return data only if credentials have already been saved.
API Setup
Opens the screen for saving, updating, or deleting the active exchange's encrypted local credentials. The form never shows the actual secret after it has been saved.
Agent Setup
Opens the local Hermes Agent runtime check and Arrow preferences. From there, you can verify the installation and customize the tone or focus without changing the base policy.
02 · CONNECTION SCOPE

Active Exchange

Selects the account Synapse should query: Binance Global, Binance US, or Coinbase. Changing the exchange reloads its parameters, credential status, monitor, and account data independently.

  • Selection does not execute orders.
  • Credentials are stored separately for each exchange.
  • The icon identifies the active exchange visually.
03 · ASSISTANCE MODE

AI Agent (Arrow)

The toggle enables or disables Arrow assistance in the side chat. When enabled, Arrow can analyze the non-secret state shown by Synapse and suggest controls that already exist in the interface.

  • Arrow does not open positions or create new trades.
  • It can suggest parameter or monitor changes through validated controls.
  • If Hermes is not ready, the chat remains locked and takes you to Agent Setup.
04 · LOCAL POSITION MONITOR

Start and Stop

The monitor periodically queries the exchange from this computer to keep the dashboard up to date. It is not a trading engine: it does not open entries or launch strategies automatically.

Start
Starts local reads from the active exchange. It then updates the account and marks the status as RUNNING.
Stop
Stops the monitor's periodic queries. It does not delete credentials, parameters, or data already displayed.
READY / OFFLINE
READY means credentials are available and the monitor is stopped; OFFLINE indicates that local configuration is missing.
05 · BOT CONFIGURATION

Parameters and Configure

The side panel is a live summary of the 12 values saved for the active exchange. Configure opens the editable form; when saved, the values are stored locally for that exchange.

  • Position update interval (ms): refresh frequency.
  • Take profit percentage of capital: take-profit threshold for capital.
  • DCA relative percentage: base DCA proportion.
  • DCA distance multipliers: distance for each level, for example [1, 2].
  • Stop-loss distance multiplier: stop-loss distance multiplier.
  • DCA quantity increment (%): quantity increase per level.
  • Minimum DCA distance (%): minimum distance before another DCA.
  • Maximum open positions: open-position limit.
  • Stop-loss percentage: stop-loss percentage.
  • DCA percentage increment: percentage increase between levels.
  • Breakeven ROI threshold: ROI at which breakeven is considered reached.
  • Auto-shutdown (minutes): minutes before automatically stopping the monitor.

These values are displayed and persisted locally. By themselves, they do not turn the monitor into an order executor.

06 · ACCOUNT SNAPSHOT

Account Balance, Available Capital, Total Value, and Open Positions

These cards summarize the latest snapshot received from the exchange.

Account Balance
Account balance according to the exchange and displayed market.
Available Capital
Capital available for trading or free margin, depending on the active integration.
Total Value
Total value calculated from the available normalized data.
Open Positions
Number of open positions; the market, such as SPOT or PERPETUALS, is shown below.
07 · DIRECT EXCHANGE DATA

Open positions, Pending Orders, and Close position

This area shows the normalized direct response from the selected exchange, not data invented by Arrow.

  • Open positions: lists symbol, side, size, entry, mark price, unrealized PnL, and risk.
  • Pending Orders: switches to pending orders and shows symbol, side, type, price, quantity, status, and Reduce Only.
  • Select: marks a specific position for a later action.
  • Close position: remains disabled until a position is selected; it then requires confirmation and revalidates that the position is still open with the same quantity.
08 · LOCAL EVENT STREAM

Activity and Clear

Activity records important local-use events: monitor starts and stops, saved changes, Arrow responses, errors, and completed actions.

  • The green dot identifies successful events.
  • The pink dot marks warnings or stops.
  • The red dot indicates errors.
  • Clear clears the visible list; it does not delete credentials, parameters, or exchange state.
09 · RISK ASSISTANCE

Arrow Agent: analysis inside Synapse

The right panel is Arrow's conversation space. It receives the current non-secret snapshot of positions, orders, metrics, exchange, and parameters to help you interpret risk and status.

  • LIVE means Arrow is enabled and Hermes is ready.
  • STANDBY means it is disabled or Agent Setup is incomplete.
  • Proposed actions use only controls allowed by Synapse and are applied through visible buttons.
10 · CONVERSATION

Ask Arrow and Send

Write a question about the current state and press Send. You can also press Enter to send; Shift+Enter preserves a line break.

  • The counter indicates how many positions are included in the context.
  • Recent history is retained in the conversation for follow-up questions.
  • Arrow does not receive API keys, secrets, tokens, or the Coinbase private key.
  • If it requests an action, Synapse validates it and shows the result in Activity.
11 · LOCAL SAFETY STATE

Local runtime

The bottom line of the rail summarizes the active environment: selected exchange, local state, and desktop source.

  • The green dot indicates that the local interface is available.
  • Local runtime · [exchange] confirms the currently selected exchange.
  • LOCAL ENCRYPTED · DESKTOP SOURCE reminds you that credentials are protected with Windows secure storage and that the app runs from the desktop.
